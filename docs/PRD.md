# Cercus 框架需求与架构设计说明书 (PRD)

> **版本**: 1.1 · **状态**: 持续演化规范 · **维护者**: wray-lee

---

## 1. 概述与背景

Cercus 是为蟋蟀逃逸行为神经学研究定制的全流程数据分析系统。框架接收高频运动学 CSV 传感器数据，经过轨迹滤波、时空对齐与运动学积分，自动完成行为分类（Escape / PreEscape / PreWalk / NoResponse），生成符合顶级期刊（Nature / Science 风格）出版标准的矢量图表，并提供基于分层 MCMC 的多感官整合贝叶斯推断。

系统的核心价值在于：**以确定性、可复现、抗噪声的算法替代繁重且存在主观偏差的人工试次打标**，确保长周期、多条件行为学实验在统一严格的标准下高效推进。

---

## 2. 核心挑战与应对

1. **分类主观性与重叠边界**：
   - 过去人工打标对“刺激前微弱走动”与“纯风诱导逃逸”界限模糊。
   - **应对**：构建严格单向优先级级联判定（`NoResponse > PreEscape > PreWalk > Escape`），将多模态提前起跑与风前行走明确成类。
2. **被试间运动学分布异质性**：
   - 不同蟋蟀个体的生理机能与爆发力存在天然差异，固定阈值容易在体型差异较大的动物间失真。
   - **应对**：构建四级自适应爆发阈值级联（KDE 凹谷法 → 对数 GMM → IQR 截断 GMM → 兜底回退）。
3. **海量试次并行处理吞吐量**：
   - 实验涉及多范式、数十只被试、成百上千个试次。
   - **应对**：利用多进程在数据解析与矢量绘图双层实现近线性加速。
4. **多感官因果反应时间分离**：
   - 需严格剥离视觉提前触发的提前量（Lead time）、刺激诱导的制动停顿（T1）与重新起跑（T2）。
   - **应对**：基于硬件采集时钟与因果位移平均建立独立的 RT 测量系统。

## 3. 功能需求矩阵

### 3.1 数据摄入与管理 (Data Ingestion)

- **自动探测与配对**：递归扫描输入目录，依据 `{subject}_session_{N}_events.csv` 与 `{subject}_session_{N}_kinematics.csv` 正则自动配对。
- **元数据动态解析**：自动解析 Events 表中 JSON 格式的刺激参数（如 `target_ttc_ms`、刺激角度等）。
- **健壮性保障**：对空文件、残缺列或断流时间戳给出清晰的预警提示并安全跳过。

### 3.2 运动学计算核心 (Kinematics Core)

- **瞬时与均值速度**：从编码器位移标量解算瞬时速率，并配合 Savitzky-Golay 滤波降低传感器高频噪声。
- **纯物理模块解耦**：核心物理与空间积分模块（`cercus.core.kinematics`）严格隔离绘图依赖，保证计算轻量与高复用性。
- **双阶段轨迹积分**：
  - **Stage 1 (局部弯曲)**：按帧积分角位移 dz，完整重现蟋蟀逃逸中的“S 型”规避走位。
  - **Stage 2 (刚体宏观偏转)**：结合主要转向冲量实施刚体旋转，呈现群体向背离刺激方向逃逸的扇形离散度。
- **回溯潜伏期定位**：从符合爆发标准的峰值样本向回追溯，精确定位速度脱离静止基线的起始帧（Onset）。

### 3.3 行为分类状态机 (Classification Pipeline)

- **优先级级联**：
  $$\text{NoResponse} \succ \text{PreEscape} \succ \text{PreWalk} \succ \text{Escape}$$
- **PreEscape 支持**：支持起跑时刻回溯跨越刺激到达时刻，将视觉提前诱发的逃逸与风后逃逸彻底分离。
- **PreWalk 运动资格审查**：前置 1 秒硬件时钟历史完整，因果均速超过 10 mm/s 占比达标且到达瞬间维持运动。
- **端点缺失透明性**：端点无法测量（如持续高速未回落）时保留行为分类，物理 RT 如实置 NaN。

### 3.4 出版级图表输出 (Visualization)

- **视觉规范**：内置 Nature/Lancet 风格高对比调色板与规范排版，默认输出无损矢量 SVG。
- **图表家族**：
  - 轨迹全景图（按行为类别分类着色）
  - 速度与角速度动力学均值及离散度曲线（对齐至 TTC / 刺激到达）
  - 起跑对齐热图与全试次高分辨率热图
  - 极坐标逃逸角度分布玫瑰图（含 Rayleigh 均匀性检验标注）
  - $V_{max}$ 拟合分布诊断图与疲劳习惯化曲线
  - 反应时间与逃逸位移复合面板图

### 3.5 贝叶斯 MCMC 推断 (Bayesian Inference)

- **心理物理函数拟合**：以 TTC 为自变量拟合逃逸概率 Sigmoid 曲线。
- **多感官假设检验**：提供基于 ROPE（实质等效区域）的后验检验，评估双模态协同效应。
- **双后端支持**：原生支持 PyMC 与 NumPyro（JAX 加速，支持大幅提速采样）。

---

## 4. 非功能与工程质量约束

1. **执行隔离与环境**：所有计算链路要求在配置完整的 WSL Linux 容器/Conda 环境中原子化执行。
2. **全配置驱动**：严禁在核心算法中硬编码物理阈值、几何参数或样式颜色，统一收敛至 YAML 并在加载时接受 Pydantic 模式校验。
3. **防漂移回归测试**：
   - 分类器依托 10 组典型边界合成试次做位级回归（Golden Test）。
   - 图表渲染建立像素级 SHA-256 哈希基线校验，确保视觉重构不发生静默形变。
